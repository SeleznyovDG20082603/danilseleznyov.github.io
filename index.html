Hermes rclone backup

Personal, single-user command-line backup tooling (rclone wrapper).

This application is a private automation tool. It runs on its owner's own server and uses rclone as a client for the Google Drive API to upload and rotate compressed (xz) snapshots of the owner's SQLite databases into the owner's own Google Drive account.

What it does

  • Creates local snapshots of the owner's database files and compresses them.
  • Uploads them into a folder created by the tool in the owner's own Google Drive (hermes-db-backups/).
  • Deletes backups older than the retention period (7 days) to free space.
  • Nothing else: no reading of unrelated files, no analytics, no telemetry.

Who uses it

  • A single user — the owner of the Google account and of the server. There are no other users, no sign-up, no multi-tenant access.
  • The tool is non-commercial and is not distributed as a service.
