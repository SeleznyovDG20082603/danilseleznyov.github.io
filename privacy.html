Privacy Policy — Hermes rclone backup

Last updated: 2026-10-05

Hermes rclone backup ("the app") is a personal, single-user command-line backup tool. This policy describes how it accesses, uses, stores and shares Google user data.

1. Google user data the app accesses

  • The app authenticates with the owner's own Google account using OAuth 2.0 and requests a single scope: https://www.googleapis.com/auth/drive.
  • Access is used only to create, list, download and delete backup archives inside the folder the app manages in that same account (hermes-db-backups/).
  • The app does not read, modify or delete any other files in Google Drive, and does not use Gmail, Calendar, Contacts, Photos or any other Google service.

2. How the data is used

  • Only for the single purpose of storing and rotating the owner's own database backups.
  • No profiling, no advertising, no analytics, no automated decision-making.
  • No machine learning or AI model training on Google user data.

3. Storage and retention

  • Backup archives are stored in the owner's own Google Drive account.
  • No copy of Google user data is transferred to any other party or service.
  • Archives older than 7 days are deleted automatically (rotated) to free space.

4. Sharing

  • The app shares no Google user data with third parties.
  • Data is not sold, rented or transferred for advertising or any other purpose.
  • No humans read the data; access is limited to the owner of the account.

5. Security

  • OAuth 2.0 credentials are stored on the owner's own server, protected by file-system permissions and not shared publicly.
  • Access can be revoked at any time at myaccount.google.com/permissions.

6. Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
